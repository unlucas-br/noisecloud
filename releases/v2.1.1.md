Corrige a dependência externa de FFmpeg da versão 2.1.

- **Executável completo:** o FFmpeg está compactado dentro do `ncc.exe`.
- Encode e decode funcionam sem instalar FFmpeg, configurar PATH ou baixar componentes no primeiro uso.
- O runtime é preparado automaticamente no cache do usuário, com verificação SHA-256 e recuperação de cache corrompido.
- Publicação validada copiando somente o EXE para uma pasta nova e testando encode/decode com PATH vazio.

**Windows 64 bits:** baixe `ncc.exe` e execute. O ZIP inclui o mesmo executável, documentação e licenças. O programa precisa de espaço para extrair aproximadamente 100 MB no cache do usuário.

Inclui as melhorias do Weave e Zstandard da 2.1, preservando a leitura de vídeos antigos com Gzip.

FFmpeg 9.0.1, build estático GPLv3 de [Gyan](https://www.gyan.dev/ffmpeg/builds/). Origem e checksums estão em [`internal/ffmpeg/bundle.json`](https://github.com/unlucas-br/noisecloud/blob/v2.1.1/internal/ffmpeg/bundle.json); licença e informações do build acompanham o pacote e o runtime extraído.

Verifique os downloads com `SHA256SUMS.txt`.
